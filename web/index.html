Waiting for a headset…
F1–F5 or ← →  ·  Esc close

This panel is the box's own settings. It opens with F12 and closes with Esc. While it is open the keyboard and mouse belong to this screen; everything else you type goes to the headset.

F1
Help — this page.
F2
Internet Wi-Fi — joins this box to a venue's Wi-Fi so it has internet, using the USB adapter. This is not the headset network, which is fixed and always on. Also holds the radio band plan: the two radios must never share a band.
F3
Bluetooth — pairs a Bluetooth keyboard or mouse to the box, so you do not need one plugged in. Scan, pick a device, and follow the prompt.
F4
Steering wheel — for a USB racing wheel. Assigns which axis is steering, gas and brake, sets the rotation range and the spring-to-centre strength.
F5
Vehicle sensors — for a Drive Square USB sensor rig clamped to a real car's wheel and pedals. Appears only when one is plugged in. Two keypresses: zero everything, then move everything.
F12
Open or close this panel. It works while a headset is casting — the video steps aside and comes back on its own.
Ctrl+S
Re-centre the steering. Takes wherever the wheel is now as dead ahead, without disturbing its calibration.
Esc
Close the panel, or cancel whatever step is running.
